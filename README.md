# Free Fire Shooter

A small browser-based shooter inspired by battle royale gameplay. This project is built with plain HTML, CSS, and JavaScript so it runs instantly in a browser with no dependencies.

## Features

- Move with WASD or arrow keys
- Aim with the mouse
- Shoot with click or space
- Enemies spawn continuously over time
- Health bar and score system
- Restart button and restart key
- Responsive canvas layout

## How to run

Option 1: open `index.html` directly in a browser.

Option 2: serve locally:

```bash
cd free-fire-game
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Project structure

- `index.html` – page structure and HUD
- `style.css` – visual design and layout
- `game.js` – gameplay logic and rendering

## Notes

This is a lightweight, playable prototype designed as a starting point. You can expand it with sound effects, power-ups, multiple weapons, a larger map, mobile controls, or a more polished battle royale style.
